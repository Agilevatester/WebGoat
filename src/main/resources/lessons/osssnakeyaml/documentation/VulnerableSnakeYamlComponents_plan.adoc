Then test and deploy. Done!

## Quick Reference

=== Vulnerable Code (DON'T DO THIS)
[source,java]
----
Yaml yaml = new Yaml(new Constructor());
Object obj = yaml.load(userInput);  // ← EXPLOITABLE
----

=== Safe Code (DO THIS)
[source,java]
----
Yaml yaml = new Yaml(new SafeConstructor());
Object obj = yaml.load(userInput);  // ✓ SAFE
----

=== Check if You're Vulnerable
[source,bash]
----
mvn dependency:tree | grep snakeyaml
# If < 2.0, you're vulnerable
----
