Challenge: Customer Directory Lookup

Difficulty: ★★★★

Scenario: A customer management portal exposes a directory search endpoint backed by a Spring Data MongoDB repository. The search accepts a customer name and optional result preferences.

Investigate how the repository processes the search term when it is forwarded to the underlying query engine. Consider what query binding mechanisms Spring Data MongoDB uses internally, and whether supplying non-literal values produces unexpected behaviour.
